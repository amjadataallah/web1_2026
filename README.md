## Course Overview

Web 1 introduces the fundamental technologies used to build websites and web pages. The course focuses on understanding how web pages are structured, styled, and organized using core web technologies.

Topics covered during the course include:

- Introduction to the Web and how websites work
- HTML fundamentals
- HTML elements, tags, and attributes
- Links, images, lists, and tables
- HTML forms
- Semantic HTML
- CSS fundamentals
- CSS selectors and properties
- Colors, fonts, backgrounds, borders, and spacing
- The CSS Box Model
- Page layouts
- Responsive web design
- Basic web development best practices
- Git and GitHub basics for managing web projects
